All filenames below are lowercase and must match exactly. Place every generated image into this public/images/ folder.
The website has designed fallback artwork, so it still looks complete before you add your own images.

Recommended format: WebP or JPG for photos, PNG only if transparency is needed. Keep images compressed for fast pages.

OPTIONAL ARTICLE IMAGES
-----------------------
For every newly published article, use a unique descriptive filename such as article-retirement-planning.jpg and upload it from Workspace > News & Insights. Supabase mode uploads article images to the article-images bucket; preview mode keeps uploaded files in this browser only.

HOW TO REPLACE A PLACEHOLDER
----------------------------
- Generate or download the image to your computer.
- Copy the file into public/images/ and use the exact filename above.
- The homepage hero and article cards will display the matching file automatically.
- To use a different filename, update the src path in src/App.jsx near the matching IMG ID.
- Never add an image ID as a filename by itself. IDs are labels in the code; filenames are listed above.
